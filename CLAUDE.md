## Build & Run Commands

```bash
# Build the mod JAR
./gradlew build

# Launch Minecraft client with the mod loaded (primary way to test)
./gradlew runClient

# Run dedicated server
./gradlew runServer

# Regenerate placeholder textures (spawn eggs, discs, entity skins)
python gen_textures.py
```

There is no automated test suite — all testing is done by running the client and exercising features in-game.

## Project Overview

**Galgochim** is a Fabric mod for Minecraft 26.2, written in Java 25. It adds three creatures (Galgoach, Pilapa, Karner), two spaceships (Hagit / alien ship), a villager NPC (Doron Fishler), two blocks (microphone, washing machine), several items, and three music discs.

## Architecture

### Entry Points
- `Galgochim.java` — server-side `ModInitializer`. Calls each registry class in order: Sounds → Entities → Blocks → Items → Villagers → Spawns → Loot → Events → Commands.
- `client/GalgochimClient.java` — client `ClientModInitializer`. Registers entity renderers and model layers.

### Package Layout

| Package | Purpose |
|---|---|
| `registry/` | All `Registry.register(...)` calls — one class per domain (entities, items, blocks, sounds, villagers, spawns, loot, events, commands) |
| `entity/` | Entity logic (`*Entity.java`) |
| `item/` | Non-trivial item behaviour (`ChronoItem`, `SockItem`) |
| `block/` | Block logic (`WashingMachineBlock`) |
| `mixin/` | Server-side Mixin patches |
| `client/model/` | `EntityModel` subclasses (geometry) |
| `client/renderer/` | `EntityRenderer` subclasses (textures, layers) |
| `client/mixin/` | Client-side Mixin patches |

### Data-Driven Content (`src/main/resources/data/galgochim/`)
- `jukebox_song/` — music disc definitions
- `recipe/` — crafting recipes for blocks
- `trade_set/` + `villager_trade/` — Doron Fishler's trades (MC 26.2 fully data-driven villager trade system using `Int2ObjectMap<ResourceKey<TradeSet>>`)

### Assets (`src/main/resources/assets/galgochim/`)
- `lang/en_us.json` and `lang/he_il.json` — all display strings (mod is bilingual English/Hebrew)
- `textures/entity/` — entity skin PNGs (many generated by `gen_textures.py`)
- `items/` + `blockstates/` + `models/block/` — standard Minecraft model JSON

### Commands
- `/tooglehgit` — summon/toggle the Hagit spaceship
- `/tooglealians` — summon/toggle the alien ship

### Audio Placeholders
`wilhelm_scream.ogg` and `amar_hakaptan.ogg` are placeholder files. See `SOUNDS_TODO.md` for instructions on replacing them with real audio.

### Offline / Constrained Build
The project must build offline (no Maven Central access during development). All dependencies are resolved through Fabric's Loom plugin and the local Gradle cache.
